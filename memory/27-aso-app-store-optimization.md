# ASO(App Store Optimization) — 필타임 스토어 검색 최적화

**최종 갱신**: 2026-07-18

앱스토어 검색 최적화 딥리서치 결과 + 필타임 적용 체크리스트.
펴볼 때: "스토어 제목/부제/키워드 뭐 넣지", "iOS vs Android 키워드 어떻게 다르지",
"스토어 업데이트 전 ASO 점검". (딥리서치: 소스23·확정15·기각8, 적대검증 3표)
용어: AEO=AI답변엔진 최적화(다른 것). 앱스토어 검색은 ASO.

## SEO vs ASO — 개념은 같고 메커니즘이 다름
- 검색의도: SEO=정보탐색(결정 전) / ASO=설치 직전(짧고 행동지향)
- 인덱싱: SEO=크롤러가 페이지 전체 / ASO=**제출한 특정 필드만**
- 백링크: SEO 핵심 / ASO **없음**(외부링크 무관)
- 콘텐츠품질 역할: SEO=본문 / ASO=**스크린샷·아이콘**(전환 유발)

## ★ iOS vs Android 인덱싱 차이 (실무 핵심 — 같은 키워드 다르게 배치)
**iOS(App Store)** — 검색 인덱싱 필드 3개, 가중치 **앱이름 > 부제 > 키워드필드**:
- 앱 이름 30자(최고 가중치) / 부제 30자(2위) / 숨은 키워드필드 100자(유저 비노출, 3위)
- **설명(description)은 랭킹 인덱싱 안 됨** — 전환(설득)에만 기여
**Android(Google Play)** — 전용 키워드필드 없음:
- **긴 설명(4,000자) 전체 키워드 밀도가 직접 랭킹 요소**(웹 SEO에 가까움) + 짧은설명 80자
- Play는 설명문에 타겟 키워드 자연 반복(2~3회)

## 애플 키워드필드 100자 규칙 (검증됨)
- 쉼표 구분·공백 없이(`시간기록,몰입` — 공백은 글자 낭비)
- 제목·부제에 쓴 단어 반복 금지(알고리즘이 전 필드 자동 조합)
- 조사·전치사 빼고, 롱테일 구는 단일어로 쪼개기(`무료 시간 관리 앱`→`시간,관리,무료`)
- **한국어 특수성**: 띄어쓰기가 토큰 경계 → `업무시간`≠`업무 시간`. 전문툴이 형태소분석 알고리즘 별도 제공(ASO index). 붙여쓴 형태 위주 + 실제 검색 변형 혼용

## 평점·A/B 테스트 (검증됨)
- **평점 3.5 미만=노출 급감 / 4.0 이상=순위·발견성 상승** → 필타임 4.0 사수가 생존선
- 애플 PPO: 변형 3개·트래픽배분·최대90일. 한계=동시 1테스트만/텍스트 테스트 불가(시각만)/지역별 결과 없음/신뢰수준 90%고정
- 구글 스토어 실험: 변형 3개, 아이콘·짧은설명·스크린샷·긴설명 다 테스트·5개언어 → 애플보다 유연

## ⚠️ 기각된 통설 (적대검증에서 죽음 — 믿지 말 것)
- "전환율이 직접 랭킹 입력값"(1-2 기각): 벤더 주장, 애플 미확인. 개연성O 확정X
- "다운로드 속도·리텐션이 App Store 랭킹 신호"(0-3 기각): 벤더 통설, 미확인
- "리뷰 최신성 > 평균 별점"(0-3 기각)
- "ASO index 100% 무료"(기각)
- 결론: 확실한 레버 = 메타데이터(제목·부제·키워드필드)+스크린샷+평점4.0. 행동신호(전환·리텐션)는 회색지대

## 🎯 필타임 적용 체크리스트
**iOS(라이브 — 다음 업데이트에 반영)**
- 앱이름 30자: 브랜드+최상위키워드 예 `필타임 - 업무시간 기록 타임트래커`
- 부제 30자: 이름에 안 쓴 키워드 예 `몰입 집중 잔디로 쌓는 습관 기록`
- 키워드필드 100자(공백X중복X단일어): 시간관리,생산성,포모도로,집중,딥워크,프리랜서,루틴,작업시간,타임로그,열품타,공부,플래너,체크리스트,할일
- 설명문=전환(첫3줄 후킹) 집중 / 스크린샷 첫1~3장이 검색결과 인라인 → 핵심가치 몰빵(블루잔디 애셋 재활용)
**Android(심사중 — 등록정보)**
- 긴설명 4,000자에 타겟키워드 자연반복(시간기록·타임트래커·업무시간·집중·습관 2~3회씩)
- 짧은설명 80자 최상위키워드 / 승인 후 스토어실험 스크린샷 A/B
**공통 무료 워크플로우**
- ASC Search Terms 리포트 + Apple Ads Search Popularity(0~100)로 키워드 볼륨
- 스토어 자동완성 후보 30~50개 → 경쟁 낮은 것부터 / 경쟁앱(열품타·Forest·토글) 벤치마크
- 평점 4.0 방어(긍정 순간 앱내 리뷰 프롬프트) / PPO 스크린샷 첫장 A/B(트래픽 쌓인 뒤)

## ★ 스토어 실측 + 실행계획 (2026-07-18, ASC API 조회)

### 현재 iOS 상태 (버전 1.0 READY_FOR_SALE, ko 로케일)
- **앱 이름(name)**: `필타임` — ⚠️ 브랜드만. 30자 최고 가중치 필드에 검색 키워드 0개
- **부제(subtitle)**: `None` — ⚠️★ **완전 비어있음**. 30자 2위 가중치 필드 통째 낭비 = 제일 큰 개선 기회
- **키워드(keywords 100자)**: `업무시간,타이머,시간관리,생산성,할일,투두,근무기록,집중,시간기록,워크타임` (~46자, 54자 여유)
- promoText 있음(랭킹 무관, 전환용)

### 개선안 (ASC에서 손으로 교체 — 복붙용, 실제 볼륨은 ASC Search Terms로 검증 후 확정)
- **name(30자 이내)**: `필타임: 업무시간 기록 타임트래커` (18자) — 브랜드+최상위 키워드. 심사/브랜딩 안전선
- **subtitle(30자 이내)**: `몰입·집중을 잔디로 쌓는 습관 기록` (~19자) — 몰입/집중/잔디/습관/기록 담김
- **keywords(100자, 공백X·쉼표구분·name/subtitle 중복 제거)**:
  `시간관리,생산성,딥워크,포모도로,스트릭,프리랜서,재택근무,루틴,타임로그,플래너,집중력,열품타,투두,할일,근무기록,시간기록,작업시간` (~76자)
  - name/subtitle에 이미 든 필타임·업무시간·기록·타임트래커·몰입·집중·잔디·습관은 뺌(중복=낭비)
  - `열품타`(경쟁앱 브랜드) 포함 — 경쟁앱 검색 유저 흡수용
- **적용 위치**: ASC → 앱 → (해당 버전) → App Store 정보 → 한국어 → 이름/부제/키워드. 편집하려면 "편집 가능" 상태 필요(새 버전 or 기존 버전 준비상태). v1.0.1 낼 때 같이 반영 권장
- **⚠️ 자동화 가능**: ASC API(`/tmp/asc-meta.py` 패턴, appInfoLocalizations PATCH name/subtitle + appStoreVersionLocalizations PATCH keywords)로 코드 적용도 됨. 사용자 승인 시 실행

### Android (Play, 심사중 — 등록정보 작성 시)
- Play는 키워드필드 없음 → **긴 설명(4,000자)에 타겟 키워드 자연 반복**(2~3회): 업무시간 기록·타임트래커·시간관리·집중·몰입·습관·잔디·스트릭·포모도로
- 짧은 설명(80자): 최상위 키워드 압축 예 `한 번의 탭으로 업무시간을 기록하고 잔디로 쌓는 몰입 습관 트래커`
- 승인 후 스토어 등록정보 실험으로 스크린샷 A/B

### 스크린샷 (양OS 공통)
- iOS 첫 1~3장이 검색결과 인라인 → 핵심가치(원탭 타이머·블루 잔디 벽·통계) 몰빵
- 랜딩(ss-042)에서 만든 블루 잔디/스텝 삽화 애셋 재활용 가능

### 평점 관리
- 4.0 사수(3.5 미만=노출 급감). 앱내 리뷰 프롬프트를 긍정 순간(스트릭 달성·주간리캡 등)에 노출
