# 경쟁앱 리서치 — 시간추적/집중/소셜 (리빙노트)

**최종 갱신**: 2026-07-15

필타임 경쟁 분석. 국내 시장 + 글로벌 집중/시간추적 + 소셜/스트릭/리캡 수익화 벤치마크.
펴볼 때: "경쟁앱 뭐 있지", "가격 얼마 받지", "이 기능 남들은 어떻게 했지", "광고 붙일까 말까", "페이월 어디 둘까".
로드맵은 `19-growth-roadmap.md`. 전략 근거는 `10-viral-share-strategy.md`.

> 수치 신뢰도: 매출/MAU/전환율 대부분 3rd-party(Sensor Tower/GetLatka/Trophy/StriveCloud) **추정**. 공식 확정치만 "공식" 표기. 가격은 시점·지역·플랫폼별 변동 — "구간·패턴"으로 볼 것.

## 0. 한 줄 결론 (이것만 봐도 됨)
- **화이트스페이스 실재**: 국내 타이머 앱은 100% 수험생·공부 쏠림(열품타 지배). 직장인/프리랜서 시간추적은 해외 정산툴(Toggl/Clockify)만 = 감성·동기부여·소셜 비어있음. 필타임 "일·몰입" 포지션 = 빈 공간.
- **광고 빼는 게 맞음(검증됨)**: 프리미엄 집중/시간추적 앱은 거의 전부 무광고 순수구독(Toggl·Session·Focusmate·Opal·Flow·Focus To-Do). 광고는 학생·대중 무료티어(열품타·Study Bunny)의 무기. 필타임은 프리미엄 노선 = NO ads가 카테고리 표준.
- **개인 시간추적 앱의 공통 빈틈 = 게임화 약함** → 필타임 잔디+업적+공유카드+스트릭이 명확한 차별점(게임화 없는 Focus To-Do 11M vs Forest 60M 격차가 근거).
- **가격 관행**: 월 $3.99~4.99 / 연 $29.99~44.99 + 선택적 라이프타임($12~40). 한국 로컬 월 3,900~5,900원 / 연 29,000~49,000원. 연간우선 + 7일 무료체험이 정석.

**국내 인사이트**: ①열품타 ARPU 낮음(월$6k, 광고 의존) → 필타임은 처음부터 구독 가치 명확히(리포트·공유카드·업적) 해서 저가경쟁 회피. ②경쟁자 리텐션=소셜압력(랭킹/실시간) or 게임화(나무). 필타임은 이걸 직장인 문법으로 번역 — **잔디+업적+공유카드**로. ③열품타식 랭킹경쟁·캠공부 저연령 감성은 피하고, 순공시간식 "조용한 미니멀" + 투두메이트식 "저가+AI리포트 락인" 취사선택. ④열공시간 "2주쓰면 프리미엄 무료" 트라이얼 = 온보딩에 응용 가능.

## 2. 글로벌 (시간추적 + 집중/포모도로)

**개인 시간추적** (게임화 빈틈 = 필타임 기회):
- **Toggl Track** — "감시없는 프라이버시" 표준. 광고X, Free/$9/$18(월,user). 관대한 무료. **year-in-review 개인회고 카드**(=필타임 잔디+연말결산 직결). ARR$32.8M(2024추정).
- **RescueTime** — 자동추적+**Productivity Pulse(0~100 점수)**. 광고X, $7~12/월. ★단일점수 UX = "오늘의 집중 점수" 훅 아이디어.
- **Clockify** — "영원 무료"로 침투(5M+ 공식). 광고X, $3.99~9.99. 게임화 전무 = 필타임 차별점.
- **Rize.io** — AI 자동분류 딥워크코치, 데스크탑전용, 무료티어 극협 → **반면교사**(무료 조이면 성장정체).

**집중/포모도로**:
- **Forest** — #1, 나무 게임화. 2025.12 **유료앱→무료+구독($5.99/월,$32~36/연)+코인 전환** = freemium+구독이 유료선불보다 상방 큼(시장신호). 손실회피>보상. 60M(공식).
- **Flora** — 소셜 나무심기. 유료를 "기능잠금"이 아니라 **"임팩트 강화(실나무 기부)"에 둠** → 무료유저 반발 최소화. 구독을 "제한"보다 "가치확장"으로 프레이밍.
- **Focus To-Do** — 포모도로+할일 결합($1.99/월,$9.99/연,평생$11.99). **세션↔태스크 귀속**(=필타임 session_todos, 전면에 내세울 것). 게임화無 11M vs Forest 60M.
- **Session** — 프리미엄 뽀모도로($4.99/월,$39.99/연). **세션종료 후 회고**(=필타임 세션종료 로깅모달과 같은 결). 인디 흑자.
- **Flow** — 가성비 포지션($2.99/월,$17.99/연,평생$39.99). 무료범위 넉넉+라이프타임.
- **Opal** — 스크린타임 차단+**Opal Score**. $19.99/월,$99.99/연(annual-first 앵커링). 하드페이월(무료 규칙1개)=리뷰반감 큼 → 필타임은 "무료넉넉+annual-first" 혼합이 안전.

**글로벌 시사점 4대 리텐션 조합**: ①단일 집중스코어(RescueTime/Opal) ②세션종료 회고(Session) ③연말/주간 회고카드(Toggl year-in-review=잔디직결) ④손실회피 연출(Forest). 소셜은 열품타식 경쟁랭킹보다 **"내 기록 자랑·스트릭 공유"(Deep Work식 GitHub그리드 + Finch식 응원)**가 프리랜서 정서에 적합.

## 3. 소셜/스트릭/리캡 벤치마크

**Strava (★최우선 벤치마크 — "커뮤니티로 위장한 성장")**
- 무료 유지(바이럴엔진): 기록무제한·피드·Kudos·클럽·**공유카드(IG스토리)**·세그먼트 상위10위. 유료: 전체리더보드·Route Builder·Training Log·Beacon·AI(Athlete Intelligence). 2020.5 대량 유료화 → 가격 인상. 월$11.99/연$79.99.
- **세그먼트 리더보드**: 글로벌 10만등 대신 "이 구간 달린 사람"만 = **이길 수 있는 크기로 준거집단 축소**.
- **이중 성취**: KOM(속도) + **Local Legend(90일 완주횟수=일관성)** → 빠른자+꾸준한자 둘 다 보상.
- **주간 스트릭**(일간X — 부상/여행에 안 깨지게). AI 주간/월간 리캡 이메일.
- **공유 루프**: 활동종료→브랜디드 카드 자동생성→원탭 IG공유(+클릭링크)→팔로워에 무료광고→가입. **공유는 절대 유료화 안 함.** 180M users.

**Duolingo (스트릭 마스터클래스)**
- 스트릭 freeze/repair → 리그 → **Friend Streak(2024, 친구 안하면 넛지)** = 개인 손실회피 < 상호책임.
- **"Duo death" 밈**(깨진 스트릭 슬픈 부엉이) 바이럴 → 100만 신규 다운로드. 스트릭 복구 = 리텐션 8%↑.
- churn 47%(2020)→28%(2023-24, 공식), DAU 5M→40M+(공식).

**스트릭/습관 앱 가격**: Streaks(일회성$5.99) / Habitica(기능전부무료, 구독=외형만) / Finch($9.99월,$69.99연) / Gentler Streak($49.99연,평생$139.99, 연50%할인 상비). 습관앱 표준 = **$39~69/연 + 7일체험**.

**Wrapped/리캡 바이럴 원리**: ①개인데이터→소셜화폐(정체성 신호) ②40% 자랑용·35% 연결용 공유(Hootsuite) ③소속감(친구와 겹침)+차별화(나만의 top1%) 동시충족 ④희소성·리추얼(연1회) ⑤**사용자가 주인공, 브랜드 아님**. 핵심: **"측정결과가 아니라 정체성"으로 프레이밍 + 약간 미화된 자기모습**일 때 공유된다.

**RevenueCat 2025 (11.5만앱, $16B 기반)**:
- **Day 0가 전부**: 트라이얼 시작 80%+가 설치 당일. 페이월 배치·첫인상 결정적.
- 온보딩 페이월(첫실행 끝)이 트라이얼 시작 ~50% 담당.
- 페이월: 플랜 2~3개, **연간 기본선택+"월대비 X% 절약" 배지**, 결과→가치→안심→가격→CTA 순.
- freemium→유료 2~5% 표준. 고가앱 다운→트라이얼 9.8% vs 저가 4.3%(**너무 싸게 잡지 말 것**). Reverse Trial(결제정보없이 프리미엄 먼저) = Strava 방식, PMF 강할 때.
- **습관앱 함정**: 7일 트라이얼 끝날 때 습관 아직 미형성 → **핵심 무료루프(기록+알림+스트릭+완료뷰)는 무료로 남겨야** churn 구조 방지. contextual paywall이 대안.
