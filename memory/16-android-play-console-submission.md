컴팩트 전엔 "입력 100% 완료, Google 사전스캔만 대기"로 적혀 있었으나 **틀림**. 실제로 `/publishing`의 "검토를 위해 앱 전송" 버튼이 계속 비활성이고 잠금 메시지("앱 대시보드에서 필수 단계 완료")가 떠 있었던 진짜 이유:
- **프로덕션 버전(AAB v2)이 "임시 출시(초안)" 상태로만 저장돼 있었고, "버전 미리보기 및 확인 → 저장" 단계를 안 거쳤음.** 대시보드 "버전 생성 및 게시" 2/5 완료 상태였음.
- 해결: 대시보드 → "버전 미리보기 및 확인" → 출시준비 1단계 "다음" → 2단계 검토(경고1개=난독화 매핑파일 없음, 무해) → **"저장"** → 게시개요 잠금 해제 → "검토를 위해 변경사항 11개 제출" 활성 → 클릭 → "변경사항 전송" 확인 → 제출 완료.
- 교훈: **AAB 업로드 = 초안일 뿐.** 반드시 트랙 릴리스 "미리보기 및 확인 → 저장"까지 해야 게시개요에 릴리스가 잡히고 제출 버튼이 열린다. 대시보드 "버전 생성 및 게시 N/5"가 5/5 근처인지로 확인.

  - `worktimer Android (upload key)` = `...8gtv0ai24q9o...` ← **업로드키 SHA-1** `84:F1:CC:...:CD:B7`
- **OAuth 동의화면 게시상태가 "테스트 중"이라 테스트사용자만 로그인 가능**했음(치명적). `/auth/audience`에서 "앱 게시" → "프로덕션으로 푸시" 확인 → **프로덕션 단계**로 전환. 기본 스코프(email/profile)만이라 별도 Google 인증 불필요.
