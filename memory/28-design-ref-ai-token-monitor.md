# 디자인 레퍼런스 — AI Token Monitor (데스크탑 앱)

**최종 갱신**: 2026-07-18

사용자 데스크탑 앱 "AI Token Monitor"(Tauri, 메뉴바 토큰 사용량 모니터)에서 필타임에
빼올 만한 디자인 요소. 펴볼 때: "잔디 입체감 어떻게", "리더보드 UI", "히트맵 뷰 구성".
(실측: 앱 실행 → 메뉴바 팝오버 육안 확인. Tauri 압축 바이너리라 CSS 원본 추출은 불가 →
본 것 + 표준 재현 기법으로 정리)

## 실제 확인한 것 (팝오버 구조)
- **탭 구성**: 개요 / 분석 / 🏆리더보드 / 채팅 — 상단 탭
- **서브 토글**: Claude / Codex (소스 전환) + 오늘 / 이번주 / 이번달 / **그리드** (기간)
- **리더보드**: 아바타 원형 + 큰 수치(토큰) + 보조 수치($) 2단, 랭킹에 트로피/메달, #21/40 식 내 순위 배지
- **색 절제**: 청록 단일 액센트 + 뉴트럴(회색) 배경 → 차분함
- **그리드(잔디) 뷰**: 기간 토글 안에 별도 뷰로 존재 (연간 그리드 + 기간 요약 전환)

## 빼올 것 → 필타임 적용

### 1. ★ 잔디 셀 입체감(depth) — 지금 평면 → "떠오른 키캡"
평면 단색 셀을 살짝 볼록하게. CSS(랜딩) 기준:
- 셀 미세 그라데이션: `linear-gradient(155deg, {밝은변형}, {기준색})`
- 상단 하이라이트(inset): `box-shadow: inset 0 1px 0 rgba(255,255,255,0.4)`
- 컬러 드롭섀도(떠오름): `box-shadow: 0 1px 2px rgba({셀색},0.22)` (2·3 콤마 합침)
- 라운드 유지(`rounded-[3px]`)
- ⚠️ 앱(RN)은 box-shadow 제한 → iOS `shadowColor/Offset/Radius` + Android `elevation`,
  또는 `expo-linear-gradient`로 셀별 그라데이션. 연한 색 + 입체감 조합이 고급스러움

### 2. 리더보드 레이아웃 → Phase 5 소셜(친구 피드/랭킹)
아바타원 + 큰 지표(누적시간/스트릭) + 보조지표 + 트로피 + 내순위 배지 구조 그대로 차용.
19번 로드맵 Phase5 "이길 수 있는 범위(친구/코호트) 리더보드"와 결합.

### 3. 히트맵 뷰에 기간 토글 → 오늘/주/월/그리드
현재 기록탭(캘린더/히트맵/통계 분리)을 이 앱처럼 "한 화면 + 기간 토글"로 압축 검토.
그리드(연간 잔디) = 기본, 오늘/주/월 요약 = 토글. 마이그레이션 부담 있으니 검토만.

### 4. ✅ 색 절제(연한 강도) — 이미 반영됨
"많이 쓰이는 파란색이 흔하고 쨍하다"는 피드백 → 브랜드 블루를 밝은 스카이(A안)로 완화
(랜딩 `de30261`·앱 `e603291`, 잔디는 불변). 이 앱의 "단일 액센트 + 뉴트럴" 방향과 일치.
